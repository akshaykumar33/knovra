# Knovra premium product redesign prompt

Redesign every Knovra route as one coherent, high-trust developer product. The experience should feel like a funded infrastructure company: precise, calm, technical, and expensive without being flashy. Use a deep graphite canvas, near-black navy surfaces, restrained electric violet and cyan accents, crisp 1px borders, soft ambient gradients, and generous whitespace. Establish a clear type scale with a strong display face for page titles, highly readable body text, and a mono face only for code, metadata, and telemetry.

Make the first viewport useful immediately. Each page needs one dominant task, one clear heading, a short explanation, and a primary action. Use consistent 8px spacing rhythm, 12–16px card radii, 1200–1440px content widths, and responsive grids that collapse cleanly below 900px and 640px. Never let text, controls, tables, graphs, or code overflow horizontally on mobile.

Create hierarchy through scale, contrast, and alignment rather than excessive gradients, badges, shadows, or decorative panels. Cards should be quiet surfaces with subtle borders and one deliberate accent. Buttons should have clear primary, secondary, hover, focus, disabled, loading, success, and error states. Use motion only to explain state changes; respect reduced-motion preferences.

Audit every route for empty, loading, error, and populated states. Replace placeholder-sounding copy and unsupported claims with concise product language. Preserve the product’s local-first, privacy-conscious identity. Every screen should feel like it belongs to the same operating system.
