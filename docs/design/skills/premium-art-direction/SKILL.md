name: premium-art-direction
description: Develop a distinct visual direction and page concepts for premium websites and developer products.
---

Translate the user's taste into a concrete composition before changing styles. Inventory the real routes and each page's dominant task. Establish a shared visual contract: palette roles, display/body/mono type roles, density, navigation, and one signature visual motif. Create page-specific compositions rather than repeating a dashboard card grid everywhere.
When image references are requested, use the available image-generation tool, preserve every final in the project, and label references as concepts. Generated copy and metrics are proposals; do not turn them into product claims. Use the chosen reference to decide hierarchy, spacing and layout, then implement semantic responsive components instead of embedding a screenshot as the interface.
For Knovra, inspect docs/design and docs/PREMIUM_PRODUCT_DESIGN_PROMPT.md if present. The desired tone is editorial, technical, spacious and refined. Preserve existing useful functionality. Compare the implementation to the reference at both desktop and phone widths.
