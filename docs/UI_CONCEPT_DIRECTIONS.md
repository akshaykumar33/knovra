# Knovra visual concept directions

Image generation was unavailable during this pass, so these are the implementation boards the team will follow until visual generation resets.

## Direction A — Obsidian Command Center (chosen)

Near-black graphite canvas, thin blue-gray rules, one electric cyan action color, and violet reserved for selected graph state. Wide editorial page titles, compact mono metadata, quiet cards, and one dominant work surface per route. The product should feel like Linear meets a serious observability console.

## Direction B — Graphite Editorial

Warm graphite canvas, acid-lime actions, cobalt secondary state, large serif display moments, and calmer documentation-like layouts.

## Direction C — Luminous Enterprise

Dark navy surfaces, mint primary actions, ice-blue information state, and soft ambient glows.

## Implementation rules for Direction A

- One headline, one supporting sentence, one primary action per page header.
- Use cards only to group a decision or work surface; remove decorative card nesting.
- Use cyan for action and focus, violet for graph selection, amber/red only for actual state.
- Keep body copy at 15–16px minimum and metadata at 12–13px.
- Prefer 24–32px page gutters, 16px panel gaps, and 12px corner radii.
- Every mobile route becomes a single-column work surface with controls above content.
