# Phase 12 — Impact Analysis

## Goal

Answer: "What might break if this changes?"

## Inputs

- file
- function
- class
- module
- database table
- API
- service

## Analyze

- callers
- dependents
- imports
- API consumers
- database relationships
- tests
- decisions/rules
- recent commits

## Output

- direct impact
- transitive impact
- confidence
- critical paths
- tests to run
- related decisions

## Acceptance criteria

Impact results are explainable and graph-backed, not purely LLM-generated guesses.
